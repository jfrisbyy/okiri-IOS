## The missing piece: a SENTENCE VALIDITY GATE

Before *any* question is generated, the system must classify the sentence into **one of three states**:

### Sentence State Classification (MANDATORY)

**STATE 1 — VALID**

* Grammatically correct
* Semantically clear
* Native-speaker plausible

✅ Allowed:

* meaning
* translation
* completion
* naturalness

---

**STATE 2 — CORRECTABLE**

* Grammatically wrong BUT
* Clear intended meaning

✅ Allowed:

* error correction
* rewrite
* choose-the-fix

❌ Forbidden:

* meaning
* translation

---

**STATE 3 — INVALID**

* No clear meaning
* Broken negation
* Fragment with no recoverable intent

❌ ALL QUESTIONS FORBIDDEN
➡ Must either:

* be discarded
* OR be rederived from a **clean reference sentence**

Your example is **STATE 3**.

---

## This is the non-negotiable rule you need

> **If a sentence cannot be translated cleanly by a human, the model must NOT ask what it means.**

Right now that rule does not exist in your system.

## The PROMPT FIX (this will actually stop the bad questions)

### COPY / PASTE — use this as a SYSTEM PROMPT

```
You are generating language-learning questions.

ABSOLUTE RULES — DO NOT VIOLATE:

STEP 1: Sentence Validation
Before generating ANY question, classify the sentence as ONE of:

A) VALID — grammatically correct and meaningful
B) CORRECTABLE — incorrect but with a clear intended meaning
C) INVALID — broken, ambiguous, or meaningless

STEP 2: Enforcement

If sentence is VALID:
- You MAY generate meaning, translation, completion, or naturalness questions.

If sentence is CORRECTABLE:
- You MAY ONLY generate error correction or rewrite questions.
- You MUST NOT generate meaning or translation questions.

If sentence is INVALID:
- DO NOT generate ANY question.
- DO NOT generate answer options.
- Output exactly: "INVALID SOURCE — NO QUESTION GENERATED"

STEP 3: Question Integrity

For every question generated:
- There must be exactly ONE correct answer.
- All options must be:
  - grammatically valid
  - semantically plausible
- NEVER include random fragments or unrelated sentences.
- NEVER use placeholder options (e.g. “other”).

STEP 4: Meaning Questions (extra strict)

You may ONLY ask:
"What does this sentence mean in English?"
IF AND ONLY IF:
- The sentence is VALID
- A native speaker would agree the sentence has one clear meaning

If not, the question is forbidden.

If at any point a valid question cannot be generated,
STOP and return: "NO VALID QUESTION AVAILABLE".
```
