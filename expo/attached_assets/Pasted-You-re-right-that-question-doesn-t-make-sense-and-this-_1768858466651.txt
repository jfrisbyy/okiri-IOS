## Why that question is broken

> **“How do you say ‘je veux pas continuer à pleurer’ in French?”**

The problem:

* The sentence is **already in French**
* The model failed to understand **source vs target language**
* This usually happens when:

  * the system prompt is underspecified
  * or the model is templating without semantic checks

This isn’t a small bug — it’s a **systemic prompt issue**.

---

## The real fix (important)

You don’t fix this by telling the model:

> “Don’t do that again”

You fix it by enforcing **hard validation rules** in the prompt.

The model needs to:

1. Know what language the *source* text is in
2. Know what language the *user is learning*
3. Refuse to generate invalid questions

---

## The correct mental model

For Okiri, every generated question must pass this test:

> “Is this a meaningful learning task for a learner of **Target Language** whose **native language** is **Source Language**?”

If not → regenerate.

---

## Copy-paste system prompt for Replit (this is the key)

Use this as your **system / developer prompt** for question generation:

```
You are generating language-learning questions for learners.

IMPORTANT RULES (DO NOT VIOLATE):

1. The learner’s TARGET language is: {{TARGET_LANGUAGE}}
2. The learner’s NATIVE language is: {{NATIVE_LANGUAGE}}

3. NEVER ask the learner to translate a sentence INTO a language it is already written in.
   - If the source sentence is already in {{TARGET_LANGUAGE}}, do NOT ask:
     “How do you say X in {{TARGET_LANGUAGE}}?”

4. All questions must be:
   - grammatically correct
   - semantically meaningful
   - helpful for learning
   - appropriate to the learner’s level

5. Before generating a question, silently check:
   - Is the sentence in the source language?
   - Is the task appropriate for the gap type?

6. If the task would be redundant, confusing, or meaningless, REWRITE the question into a useful alternative.

7. Multiple-choice options must:
   - Include exactly ONE correct answer
   - Include 2–3 plausible but incorrect distractors
   - Never include nonsense or obviously wrong options

8. Prefer tasks like:
   - “What does this sentence mean in English?”
   - “Which version sounds more natural?”
   - “Which option correctly completes the sentence?”
   - “Correct the error in this sentence”

9. NEVER generate a question that a fluent speaker would find illogical or pointless.

OUTPUT FORMAT:
Return ONLY the question and answer options.
Do NOT explain your reasoning.
```

This prompt alone will eliminate ~80% of garbage questions.

## Extra safety: add a self-check layer (optional but powerful)

If you want to be extra safe, run a **second pass validation** prompt:

```
Check the following question for usefulness and correctness
for a language learner.

If the question is confusing, redundant, or invalid,
rewrite it into a better learning question.

Question:
{{QUESTION_TEXT}}
```

If rewritten ≠ original → replace it.

## One more critical tip (this matters)

You should **ban this question type entirely**:

> “How do you say X in French?”

Replace it with:

* “What does X mean?”
* “Which version is correct?”
* “Which sounds more natural?”

This avoids 90% of translation-direction bugs.
