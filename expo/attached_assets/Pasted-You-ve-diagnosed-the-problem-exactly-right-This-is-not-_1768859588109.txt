## The core mistake (important)

You treated **gaps** like **content units**.

They are not.

A gap is a **signal**, not a lesson.

You must decouple:

* *gap detection*
  from
* *lesson generation volume*

---

## The correct mental model (lock this in)

### ❌ Wrong model

> Every gap → exactly 25 questions

### ✅ Correct model

> Every gap → variable number of **valid** questions
> capped by **semantic stability**

If a gap only supports 6 good questions, you generate **6**, not 25.

---

## The WORKAROUND you need (this is the fix)

### 🔑 Step 1: Add a “Question Viability Check” (non-negotiable)

Before generating *any* question, the system must answer:

> **Is the source sentence grammatically complete and semantically stable?**

If NO:

* ❌ Meaning / translation questions are banned
* ❌ Naturalness comparison is banned
* ✅ Only allowed:

  * error correction
  * sentence reconstruction
  * targeted micro-fix prompts

This alone would have blocked the bad question you saw.

---

## Step 2: Introduce **Flexible Question Quotas**

Instead of:

* “25 questions per gap”

Use:

* “Up to 25 questions per gap”
* With **minimum quality gates**

### Example rule

```
If fewer than 8 valid questions can be generated,
stop and mark the gap as:
"Partial Practice – awaiting reinforcement"
```

No filler. No force.

---

## Step 3: Split gaps into TWO internal types

This is big.

### Type A — Stable Gaps

* Clean sentence
* Clear intent
* Native-speaker viable

✅ Can generate:

* meaning
* completion
* naturalness
* production

### Type B — Unstable Gaps

* Fragment
* Mixed tense
* Spoken shorthand
* Incomplete thought

✅ Can ONLY generate:

* reconstruction
* correction
* guided rewrite
* “choose the best fix”

❌ Meaning questions are **forbidden**

Your example is **Type B**.

---

## Step 4: Add a “Reconstruction First” rule

For unstable gaps:

> The FIRST task must be:
> **“Which version correctly rewrites this sentence?”**

Only AFTER the learner fixes it does it become eligible for:

* meaning questions
* deeper drills

This mirrors real teaching.

---

## Step 5: Change how you think about the 25-question rule

Here’s the reframing that will save your system:

> **25 is a MAXIMUM, not a target.**

Better model:

* 8–12 high-quality prompts per gap
* spaced over days
* regenerated as context improves

Quality > quantity.

---

## The PROMPT FIX (copy/paste)

Use this **in addition** to your existing prompt:

```
Before generating questions, evaluate the source sentence.

If the sentence is:
- incomplete
- grammatically unstable

```
