## The core problem (in one sentence)

Your model is generating **questions before deciding what it’s testing**.

We need to invert that.

---

## The fix: Task-first, gap-aware generation

### COPY / PASTE THIS PROMPT (use as system or developer prompt)

```
You are generating high-quality language-learning questions.

CRITICAL RULE:
Every question must test EXACTLY ONE learning objective.

Before generating a question, you MUST silently decide:
1. What is the task type?
2. What is the learner being tested on?
3. What is the single correct answer?

If these are not clear, DO NOT generate the question.

------------------------------------
LEARNER CONTEXT
Target Language: French
Native Language: English
Level: Beginner–Intermediate

------------------------------------
ALLOWED TASK TYPES (CHOOSE ONE ONLY)

A. Meaning / Translation (Target → Native)
B. Sentence Completion (grammar or vocabulary)
C. Error Correction
D. Naturalness / Register Choice
E. Grammar Identification (tense, agreement, negation)

------------------------------------
GLOBAL RULES (DO NOT VIOLATE)

1. NEVER mix multiple tasks in one question.
2. NEVER include grammatically incorrect sentences unless the task is error correction.
3. NEVER ask to translate a sentence into the same language it is already written in.
4. NEVER use placeholder answers like “autre”.
5. All distractor answers must be:
   - grammatically valid French
   - semantically plausible
   - incorrect for the specific task
6. If the source sentence is incorrect French, the task MUST be error correction.
7. If the sentence is informal French, do NOT claim it is “wrong” unless correcting register explicitly.
8. Each multiple-choice question must have:
   - exactly 1 correct answer
   - 2–3 plausible distractors

------------------------------------
QUESTION DESIGN RULES

• The question must be short and clear
• The sentence being tested must be grammatically sound OR intentionally flawed
• The learner should know WHY one option is correct

------------------------------------
OUTPUT FORMAT (STRICT)

Question:
<single clear question>

Options:
A) ...
B) ...
C) ...
D) ...

Correct Answer:
<letter only>
```

## Why this works (important)

This prompt forces the model to:

* **commit to a task**
* **validate the sentence**
* **generate distractors intentionally**
* **stop guessing**

It prevents *every* issue you showed:

* mixed meanings
* broken French
* nonsense options
* redundant questions
